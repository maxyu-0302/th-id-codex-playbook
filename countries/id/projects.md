# 按业务问题找项目

以下把同一项目的连续修版归在一起。[交付物目录](inventory.md)保留原目录名，可定位工作簿、历史 SQL、核验记录及发布版。每个专题的先后顺序有业务含义。

| 项目或专题 | 已形成的做法、结论或交付 | 接手后先核什么 |
|---|---|---|
| 9月增收专项与M2/M3/M4客群地图 | 长账拆到账龄、金额、C卡、可联、动账。已有可联折叠和细格汇总、M4扩至D210的修订。以保存版路由复算三策略净增量。 | 结构来源月、回收参考月、预测目标月分别记录；区分零回款和无样本。[数据合同](knowledge/data-contract.md) |
| 专催方案与委外同客群回溯 | 6—9月委外提供10月专催客群历史对照。按同金额范围及可比作业模式估计，另列专催人力、工具成本和保本实收率。 | 新增客群用上月委外同客群同期做代理；显示代理来源及覆盖本金。历史同池总实收和本月经营实收分别解释。 |
| 月切部署、分案验收、错分复查 | 以日志重建分案、撤案、同户新增资产归户。按理论DPD、执行时DPD、实际队列核对；凌晨差一天且仍在同账龄的记录与跨账龄疑点分开。 | 在有效时点看债务人全部资产；月末快照无法说明月中撤案后的归属。待查样本不外发。 |
| 动账实验、外部数据与策略价值 | 用入组染色和时间固定实验池，核串组、撤案和唯一回款案件。10月外部数据报告的原始优势在控制批次、账龄、模式、本金后未稳定保留；专催点估计样本少。 | 标签取得时间先于观察期，列匹配率、回款案件数及未匹配池。该专题是相关性证据，可作为补样或试验设计依据。 |
| 每日节点预测与实际分案复盘 | 月初老案＋每日进入节点的新案；合同到期计划、退出、还本及未来D1分别建模。跨账龄按策略重分，保留同账龄去重粒度。旧库保留10月预测偏差、11月多方法核验和月中滚动版本。 | 用原目标制定版作对照，拆供给、执行日、金额档迁移、本金和去重的贡献。10月的具体回测误差见[案例](knowledge/forecast-case-20261027.md)。 |
| 人力容量、工具与通讯成本 | 在手量用有效委案区间计算，区分案件日和累计分案。工具以发送、拨打、接通、计费各自事件去重；9月曾发现短信发送与票据跨窗口导致假缺失。 | 人均通讯成本写明分子包含的线路／短信／AI等项目，分母是在职人数还是上线人天；配置存在与实际发生、结算计费分别核。 |
| AI成本与M7+用量 | 已有8—10月每日去重拨打及11月账单复核。11月1—12日的成本分析曾检出WIZ零时长语音信箱15,094次，旧算法对应2,460.11元。 | 按供应商核次数或分钟、零时长处理及结算价格。旧价格和这一段费用不可直接用于其他月份。 |
| 净实收、成本上涨拆解、月报 | 由标准化工作簿演进至v5，分全量和常规、策略和财务两个视角。定位成本变化时拆实收、人力、人天、价格、用量和总部等分摊。 | 当期result量、价、汇率各留来源。委外佣金与财务人天成本桥接；同一费用只进一次。[成本口径](../../common/finance-methodology.md) |
| 月度目标、佣金与超额提点 | 从草案、工作日版、人工三档、经理新增档到合并表。按队列再拆催员，跟踪全月目标、序时和预计达成人数。 | 只用当期已批准目标；固定提点门槛与队列追踪区分。预测超额人数要有个人累计实收、目标和剩余作业日假设。 |
| 观远、海豚、日报及经营诊断 | 从单条SQL、PK看板发展到海豚预计算、跨月配置、管理版HTML和机器人文字稿。按同期率差展开账龄、模式和客群，可切币种。 | 管理版先按账龄顺序；先看绝对缺口、同池可比性，再下钻过程。核验日期、财务桥接、冻结组和双币切换。[运行手册](operations.md) |
| Other、冻结与财务逐笔归属 | 10月历史专题解释无分案、撤案和冻结；11月日报统一以官方策略捞回标签处理。新冻结人工目标自上线日起另拆日。 | 区分历史追因、当前现金归属、经营目标三个问题；有相同资产不等于同一笔回款。[对账](receipts.md) |

**如何回答“应该切哪一组”。** 在统一案件池内展示原、现、新三个方案的实收、成本、净实收及所需在手人力。把净增量拆为路由变化和固定路由下的实收率变化，给出保本所需的最低回收率。只有前提、样本覆盖和可用人力都成立时，才把方案写成业务建议。实施后用同一客群和成熟窗口回验预期。
