# 分案预测的多方法核验与差异定位

> 历史方法与当时版本。11月经营监控的生效规则见[变更日志](../decisions.md)。

与[预测方法](forecast.md)配合使用。目标是分别回答：资格池是否完整、日期/计次是否正确、节点本金是否正确、预测误差是否可接受。汇总对平、历史回测、不同方法相近分别提供不同证据，不能相互替代。

## 核验设计与主次关系

| 方法 | 实际检查内容 | 可支持的结论与局限 |
|---|---|---|
| 有效池覆盖对照 | ODS最新分案/撤案、分层表有效池、资产逾期池做双向差集；分正常、冻结、培训、停分待补、资格待确认 | 识别缺口及范围差异；逾期资产存在不代表有分案资格，不能直接全补入 |
| 日期与计次边界 | 枚举DPD到目标月的月初/节点归属，同一债务人×账龄×节点仅一次；验证月初恰到节点、D60/61、D90/91、D210/211、月底 | 证明规则展开不重复/漏计；不证明存续系数准确 |
| 历史截点回测 | 用历史基点可得数据和当时已成熟的校准样本预测随后窗口，对照同口径实际 | 测量历史偏差；历史重建不等于当时冻结快照，不排除ETL回灌影响 |
| 上游日节点链 | D8→D31、D31→D61、D61→D91，按真实时差逐日对齐同批样本 | 检查已知新案供给方向；只比较覆盖的节点新案窗口，不与整月含老案直接相除 |
| 换校准月 | 相同有效池、合同到期、目标日，分别用两个成熟月份的数量/本金系数 | 反映校准期敏感性，不能把多个结果平均成“更准”而不解释 |
| 本金构成与方法对照 | 当前逾期＋本资产新增到期＋同债务人其他存量资产新增到期－预计扣减；另算历史本金倍率代理 | 发现漏未来期次、资产范围缺项、重复增长；本金倍率只是代理，主方法保留合同计划 |
| 连续截止日桥接 | 固定目标月和同一计算规则，对比t、t+1：新进入有效池、结清退出、补分、还本、到期、规则变化 | 区分实际业务变化、取数范围修复和预测方法修复；红日子引起补分应单列 |
| 层级与交付对账 | 明细→每日→月度→金额档→策略模式；案件日→日均在手→人数；新旧策略同池 | 证明公式连接及输出一致，不证明未来实收或实验效果 |

方法选择随可用证据调整，不要求每个简单问题都重跑全部查询。首次建模、用户质疑明显跳变、源表/逻辑变更时扩大覆盖；更新日期但规则不变时复用已验部分，重点核新增窗口与版本差异。

## 历史回测的可比条件

1. 冻结历史基点、资产/分案资格规则、节点范围、月底留案规则、币种及汇率。校准数据的结果必须在历史基点已经可观察，不能用后来发生的还款倒推成当时可知的系数。
2. 预测和实际都采用同一“月×债务人×账龄节点”计数及节点日本金。正式策略分案与特殊补分、培训、冻结分开说明。实际历史DPD仍用资产期次重建并核验。
3. 目标月尚未结束时，截取双方同一观察窗口。比如预测10/1–25就只能对10/1–25实际；不把它标成完整10月回测。
4. 同时输出预测量、实际量、绝对误差、相对误差；本金亦同。分账龄、月初老案/新案，必要时拆金额档；整体误差小可能是细格正负抵消。
5. 对样本的未来期次，仅使用基点已存在合同。使用现表加流水还原历史需标为重建数据，追查历史覆盖、回灌和同日边界，不能称为无前视风险的冻结回测。
6. 不预先承诺固定准确率。说明误差、可能原因、适用范围和是否足以支持当前决策；本金偏差大时不能因案件量接近而放行。

## 上游交叉验证

- 对每个目标日t，回查t−23的D8、t−30的D31或D61；有实际用实际，未知根节点另估。
- 迁移率分数量和本金；本金原始迁移倍率可能大于1，需解释新增到期，不把它当“回收后保留比例”。
- 日节点必须跟踪同一批债务人/资产，不能拿两天全体案件总数直接当个体迁移率。
- 上游实际、目标实际、目标预测匹配同一范围及执行/理论日期。停分导致的日尖峰可以按执行日桥接或在一致短窗内聚合，但要保留原日数据。
- 当月D8对上月D8用于趋势核验时，比同样天数、金额定义和成熟度。D8本金与未来M2本金并不相等，需要加承接前到期和扣还本。趋势只能支持方向，不能替代11月具体合同计划。

## 本金差异按因子拆解

固定一个因素后再切换另一个，输出从旧值到新值的加减桥接，而非只给百分比：

1. 截止日/资格池变化：新分、补分、退出、冻结/培训排除。
2. 当前已逾期本金变化：真实还本、资产归属、源字段或单位纠正。
3. 未来到期计划变化：本资产新增到期、同债务人其他存量资产新增到期、未知新放款是否另设情景。
4. 系数变化：数量存续、配套本金保留、宽档代理、校准月份。
5. 分档和去重变化：节点金额档、同一资产×期次、同一债务人多资产、同月跨账龄。
6. 展示/公式变化：旧缓存、范围未扩展、重复应用迁移、旧注释、舍入。

修复M2本金漏项时，应同时更新用于策略路由的节点金额档。总本金修复但金额档沿用旧值，会继续影响内催/委外分流和人力，不能视为只改一个汇总数。

## 执行核验与结果可追溯

- 查询国家为印尼，记录SQL、参数、查询状态、结果行数、截断标志及文件版本。按互斥ID分片汇总时证明分片覆盖全量、不重复；不要把`MOD(id,4)=0`单片当全量，也不要把本金抽样当全量取数。
- 结果数触及网关上限时重新切片或聚合，不能用被截断结果生成正式预测。网关限制以当前工具为准，不把本次5000行限制写成永久值。
- 数量系数按案件加权，本金系数按金额加权；不平均各格系数。保留原始分子/分母、样本量、宽档回退层级和预测间隔。
- 保留每条链中已做过的转换：原始根节点→目标节点→每日在手。尤其验证未来D1已迁移值不再重复乘迁移率，节点本金不再重复乘数量率。
- 观察期内预测案件日数，应与逐日在手求和一致；不能用月累计分案除人数作为日负载。目标日比可作业日早时，按理论或实际假设分别解释。
- 总量应满足：月初老案＋节点新案＝全月分案；未来D1≤节点新案；明细案件/本金＝每日/各账龄合计；新旧策略输入池相同。跨账龄总计可大于去重人数。
- Excel改变供给、模式份额、人数或负载等相关参数后，检查对应层级公式；恢复原输入后再导出。M3参数不能无依据改M2。只修改展示表时保留原参数和结果，不借机重算无关范围。
- 比较前一版本时保存文件/SQL哈希与截止日。对“同一截止日但重新查询有小差异”也记录来源，不能默认是四舍五入或自动忽略。

## 发现差异时如何下结论

可用“已核对一致”“有证据解释”“尚待确认”描述具体事项，不用一个笼统通过覆盖所有检查。

- 案件量不变、本金大变：优先查新增到期期次、同户其他资产、本金倍率重复、币种单位、资产关联。
- M2/M3显著增加：同时拆月初留存、已知上游节点、未来D1代理；查停分补分和源窗口，不能只说业务自然增长。
- M4–7/M7+大变：优先查D211是否月中错误撤案重分、D1000范围、存量资产池及长账留案，而非只调系数。
- 有分案记录但资格不明：保留差异清单和影响金额，不自动补入或宣称有效池绝无遗漏。
- 多个方法相近但共用同一源表：不是独立证明源表无漏数，仍需要资格/资产覆盖检查。

限制应随证据更新；不把历史差异永久当异常，也不在没有新证据时删除它。
