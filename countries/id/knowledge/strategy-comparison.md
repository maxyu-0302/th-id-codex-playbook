## 历史参考率与细格

保留月份×阶段×金额细档×C卡×可联（若采用）×首分模式的案件、本金、实收、工具用量与成本依据。用首次分案日本金定位金额格，用月内去重分案本金作实收率分母。首次模式不代表客户全月未跨模式；不要把该观察率宣称为随机实验效果。

本次参考顺序为8月整月同格同模式→9月1—19日MTD同格同模式→明确批准的同模式宽格代理或待填。可联是否参与取率需按实际版本记录，不能展示为精细可联率但暗用其他层的样本。来源字段至少保留月份、截止日、模式、匹配维度/代理层级、样本数、本金和实收。0实收有样本与无样本分开；MTD不机械按天数放大。

固定一份预测细格池N_i、A_i，三策略共用；结构参考月、预测月份、回收来源月和快照截止日分开。细格合并时用金额加权，不能平均率或把合并数据等分回细格。

## 三策略同池计算

为每个版本s保留独立路由w[s,i,m]；每个细格各模式份额和为1。模式m为专催、委外、AI、静置；未知、冲突或缺样本不能无声分配。

- 模式案件量 = ΣN_i×w[s,i,m]。
- 模式本金 = ΣA_i×w[s,i,m]。如有独立本金分流比例，以已确认本金比例为准，不擅用案件比例替代。
- 非专催实收 = ΣA_i×w[s,i,m]×r[i,m]×k[s,m]。
- 未明确设置提升的k=1。委外系数1.2表示提升20%，输入提升30%则系数1.3；界面名称和公式单位一致。
- 专催基准另定义b_i。本次沿用“选中案件在8月原策略下的混合实收率”作为专催代理起点，专催实收=ΣA_i×w[s,i,专催]×b_i×k[s,专催]。不能叫历史内催实收率；若改为同格委外基准，必须同步调整标签、来源和所有目标公式。
- 每模式净实收=实收−成本；版本总计先加金额后计算实收率、净实收率、CPS。
- 新旧净实收增量=(新实收−旧实收)−(新成本−旧成本)。该增量包含分流、模式和成本变化，可含目标提升。

同一模式在8月与10月策略中的整体率可能不同，因为流入该模式的细格集合/权重变了；即便总案件池固定也可能发生。逐格相同模式r不变，不能因此断言同模式整体率必相等。若需要隔离结构与目标，可提供“10月新路由、系数全部1”的中间桥接：旧策略→新路由基准→新路由目标。

## FINAL固定新分流计算

以10月路由冻结每行的客群池：

- 委外、AI、静置基准实收 = ΣA_i×w[10月,i,m]×r[i,m]，不带目标系数。
- 目标实收 = 同客群基准实收×目标系数（细格系数不同时先逐格算再求和）。专催基准仍按上述b_i，专催目标为基准×专催系数。
- 基准/目标实收率分别=各自实收÷同一行本金。同客群实收率提升=目标率÷基准率−1；基准为0且目标非0标“不可比”。合计提升通过总实收与总本金计算，不能把30%等输入直接写入合计。
- 专催基准与目标均按当前安排人数×人均成本，加同批通讯工具及其他成本。人数不随实收目标自动改变。此表专催净增量反映目标提升，不包含委外转内催的成本释放。
- 委外基准成本=基准实收×(佣金率+按实收计通讯率)+其他成本；目标成本用目标实收重算。按工具用量计通讯时改用对应公式，不能同时加两遍。
- AI/静置没有目标提升时，基准与目标实收、率、成本和净实收应相同。工具成本使用同一新分流池及同一成本假设。静置有实际工具支出时保留，不强制为0。
- FINAL目标净实收增量=目标净实收−基准净实收。不能与三策略切换增量相加，两者包含重叠收益。

FINAL每行至少能追溯：新分流客群、案件、本金及占比、同客群基准实收率、目标实收率、同客群实收率提升、基准/目标实收、基准/目标成本、基准/目标净实收、目标净实收增量、人力与负载。标题不写“8月策略实收”误导。

表下注明：10月池来源、三份路由版本、参考率月份及MTD降级、专催代理基准、成本算法/币种、其他成本分摊、目标系数、源表修复日期和未解决限制。“沿用现行”旁直接给出实际模式和比例。

日均在手负载≈预计案件量×平均在手天数÷当月观察天数÷安排人数；优先使用实际每日在手去重求和。观察天数与工作日口径写明，不能把月累计分案/人数称作日负载。跨队列转派或重复间隔先合并。

## 必须验证的联动

1. 新路由互斥且覆盖全部池；M3静置保留；本次M4-7新策略委外为0。
2. FINAL基准/目标本金和案件相同。AI/静置无提升时各列一致。
3. 委外系数调1时同客群实收提升及净实收增量归0；调1.2时实收及按实收费同步变动。
4. 专催目标调0%时实收和净实收增量归0；改变人数只改人力成本/负载，不自动改回收率。
5. 三策略总量对平；率由金额重算；细格→模式→阶段→总计一致。
6. 导出后重新读XLSX公式及缓存检查，不能仅凭内存计算通过。共享公式导出可能恢复旧公式，必须查实际落盘的关键列、目标系数引用和标题公式。所有公式错误均检查。
