# 分流、实收、成本、人力模型

> 历史方法与当时版本。11月经营监控的生效规则见[变更日志](../decisions.md)。

> 适用提醒：本页保留9月策略测算历史口径。2026年10月月度目标与达成任务，以[月度目标与看板](monthly-targets-and-dashboard.md)为准：9月优先、8月补缺、专催对标委外、恢复总部成本、M7+沿用9月整月。

## 选择和参考

最细建模键为月×阶段×金额原子档×C卡×可联×原作业模式。UI合并只聚合，不改底层键。预测本金和案件可分别用结构占比分配，不能用案件份额替代本金份额。

原/现行/新路线分别维护，每格各模式份额和为1。专催先圈选，其余可选委外/AI/纯净/沿用现行，混合比例可调。专催移出后不能在剩余队列重复保留。

2026年任务的回收参考优先：8月成熟月同格同模式→9月截至19日MTD同格同模式→明确、可调的代理或待填。一般任务应将参考月参数化。MTD不自动乘天数外推整月；标明未成熟、样本量和本金。金额合并/可联合并时累计回款÷累计本金。样本少/不存在和实收确为0要区分。

模式无同格样本不能套其他模式的率。可以经明确说明使用同金额同模式、更宽C卡或可联层代理，显示降级层级。纯净率高于人工本身不证明数据错：检查样本和归属，不能人为强制纯净率低于人工。历史观察比较不是因果增益。

## 计算

单格本金A、案件N、模式份额w_m、模式参考实收率r_m：

- 原实收=`A×Σ(w_old,m×r_m)`。
- 新AI/委外/纯净实收=`A×w_new,m×r_m×(1+该模式明确设置的提升率)`；未设置则不提升。
- 专催目标必须标明基线。2026年保存版为所选案件“原策略混合实收×(1+提升率)”，不是一律人工率。若用户要对标委外，改用同客群委外基线并更改标签。
- 新实收为新模式实收之和；新净实收=新实收−新成本；净实收增量=(新实收−原实收)−(新成本−原成本)。净实收率=净实收/本金；CPS=成本/实收。
- 同客群提升率是输入（原案例专催M2/M3 30%、M4 50%）；含结构整体提升率=新整体实收率/原整体实收率−1，两者不能混列。
- FINAL的旧混合基准规则已于2026-09-22替换：固定新分流，委外/AI/静置用同客群同模式基准，专催保留已说明的代理起点。完整新旧策略收益另列三策略对比；详见 [策略对比口径](strategy-comparison.md)。

## 成本与人数

后期确认的委外计价是按实收佣金：M2=30%、M3=35%、M4=45%（2026年方案参数）。不再默认用等效人力月薪替代佣金。

- 专催人工成本=安排人数×内催人均月成本；M2/M3/M4分开，合并仅由用户选择。
- 委外费=委外实收×费率；委外通讯费可按实收比例估算（M2 5%、M3 7%，其余需明确），或按工具量计费，不能两种重复相加。
- AI/静置成本按各工具用量×单价或同模式案均成本×预计案件量。分案量增加时通讯成本相应变化；“其他通讯保持不变”指同批案件切专催时的基准通讯假设，不是总量增长成本永不增长。
- 短信以计费条数计成本，另列发送次数；人工线路含振铃+接通时长及单边接通计费；AI接通>0秒，语音信箱费用按工具表。计费周期/分钟取整/币种必须核实。
- 其他成本单独绝对值输入，默认0，按明确规则分摊，不当成“成本净增加”重复抵扣。
- 委外人数可手填。参考人均创佣3500元时：人数建议=预计委外实收×费率/目标人均创佣。另列整人数安排及该人数下的人均分案、人均佣金；3500是原案例参考，不是工资。
- 人均分案优先用月需求人力，或按每日有效在岗FTE加权。不要用月内出现分案的员工去重人数，避免离职/少量分案拉低负载。`dwd_employee_daily_status_di`是排班候选表；组织表`dwd_employee_organization_df_2026`不能直接当实际出勤，需验证字段和状态。

早期等效人力替代模型仅在用户明确采用时使用：委外FTE=N/委外月人均分案；内催FTE=N/(委外月人均分案×负载倍数)；成本差=内催FTE×内催人均成本−委外FTE×委外人均成本。内催绝对人均成本填写后倍数=内催/委外，各阶段分别计算。等负载且等人均成本应差额为0。不能与佣金模型并行重复扣除释放成本。

## 对账

原/新同本金同案件池；成本及人数参数变化应产生预期变化。保留未取整等效人数与实际整数安排，说明测算采用哪一项。实收为0的CPS显示不可计算；成本为0且实收为正时CPS=0；负净实收不得藏入0。预测是情景估算，不称已实现收益。


## 工具成本修正与负载

M4-7（D91–210）与M7+（D211–999）的AI、短信分别取实际用量/费用，不沿用相互之间的案均成本。AI单价应区分普通接通与语音信箱，检查交集避免重复计费；工具费用分摊和供应商报价须标明是估算还是财务结算。短信发送量与计费条数分开，缺计费匹配单列，不能当成零成本。

本次M4-7专催4人；M2/M3分别可调。月人均分案与人均每日在手负载并列，后者考虑撤案后的实际持有天数；计算参见策略对比口径。所有人数、单价和历史工具费仅是本次版本，不作为永久默认。
