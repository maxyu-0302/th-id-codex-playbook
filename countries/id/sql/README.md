# 只读取数与交接

| 目录 | 使用时期与用途 | 输入和核对 |
|---|---|---|
| finance-202611 | 11月18日运行包中执行的官方标签、跨批次重复、财务总额三份查询模板 | 截止日和映射须与生产版本一致。仅在有权限的印尼数仓运行。先检查标签覆盖，再按期次对重叠，最后对财务总额。 |
| bi-current-202611 | 已部署观远搭建包的9个结果集读取示例 | 数据集先查 freshness，再选 main、daily、daytargets、settlement、allpool 或 PK 拆分。查本次批次内的记录。11月19日起HTML财务桥接在消费侧另有重算，旧BI SQL单独运行不能证明财务已对平。 |
| historic | 月切部署检查、动账实验、外部数据覆盖、委外成本核验、工具与分案预测的具体历史查询 | SQL带原业务期或参数。先读文件头，换月核观察窗口、实验定义和计费版本。输出含客户级键的查询仅在授权环境复核，仓库只含查询文本。 |

11月运行包的模板参数：__CUT__ 为截止日 YYYY-MM-DD，__ASOF__ 为同日 YYYYMMDD，__START__ 为月初，__END__ 为截止日次日（不含），__LOOKBACK__ 为前两个月的月初，__TAG__ 为本月策略捞回标签。仅替换文件中出现的参数。原 SQL 中固定月份的财务汇率及范围也须逐项复核。
