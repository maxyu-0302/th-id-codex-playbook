# 印尼指标与取数入口

| 指标 | 分子、分母与计次 | 易误读处 |
|---|---|---|
| 分案案件量 | 按目的区分当日节点新案、月内账龄段首分、全月唯一债务人。累计案件计次可跨账龄。 | 一个债务人多笔资产，本金先对资产期次去重，再归户。日末在手和累计分案分开统计。 |
| 分案逾期本金 | 按分案时点计算当时已逾期未还本金 | 不能套用月底余额；同户后续新增资产只在有效归户节点纳入。 |
| 全催剩本 | 取分案时点业务定义范围内的剩余本金；与只取已逾期本金形成两套分母 | 历史缺少可信全催剩本或冻结本金时，相关率值留空。 |
| 经营实收率 | 回款日经营实收／选定时点的累计分案本金；同一币种 | 专催按回款时账龄拆M2、M3、M4–7，不能仅按M2-SCQ名称归M2。未配本金的现金在诊断中单列。 |
| 首分同池实收率 | 首分队列对应固定案件池的累计实收／该池分案本金，转组仍追原池 | 用于同池跟踪。与回款当日经营归属可能有差额。 |
| 全结清率 | 当期按债务人首分去重，入组时有资产且尚未全结清、期次完整的案件作为分母。观察日名下资产全部结清计入分子。 | 无逾期但仍有未到期欠款另列；撤案不代表结清。该报表的上月同期按相同日号截断。 |
| 序时、月达成、外推 | [目标与队列规则](targets.md)；目标和预测使用各组有效作业期 | 停工日实际回款可非零；当日目标为0时日达成率留空。 |
| 财务与策略净实收 | 实收－对应范围成本；CPS＝对应成本／实收 | 先确认人力、通讯及总部等覆盖；策略估算与财务结算并列。[财务桥接](receipts.md) |
| 同期变化 | 实收和分案规模按同窗口取数，合计率按总分子／总分母。客群可进入、退出或换模式。 | 专催新客群历史对标上月委外同客群。控制账龄和金额范围，注明代理，避免用两个不同池的整体差解释效率。 |
