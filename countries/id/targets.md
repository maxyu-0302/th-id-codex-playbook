# 目标、队列与催员

追踪目标对应当月调整后业绩，日报默认使用。净实收倒推目标是由净收入目标及成本反算的实收要求。主管经理档用于管理考核。基准和基准＋△用于看目标制定过程，各列有不同用途。可读取[11月三档金额及队列分配](examples/2026-11-targets.json)，核对常规明细和冻结父组合计。冻结人工是父组子项。

| 11月规则 | 如何计算与验收 |
|---|---|
| 基准＋△ | 仅内催、委外适用。△为选定历史可比表现与基准之差。用8—10月各候选整月的汇总实收／汇总本金作参考，保留批准客群与代理来源，避免逐个极小格子取最高值后相加。其他模式该列等于基准。 |
| 管理考核 | M2-SCQ 用截至11月11日序时100%档（约31.10万元）；核对是跨三个账龄的专催队列目标还是单账龄子项。M3委外追踪16.24万、净实收倒推约15.51万。明细计算取当月配置全精度。 |
| 供应商 | 11月M2委外CPU／EDN、M3委外EDN／QIN各半；M2 AI的BY／SD、M3 AI的SD／WIZ各半。专催三账龄落到同一M2-SCQ。同一父级的配置权重合计100%。 |
| 人员 | 委外按本月确认在职名册均分。M2-CPU、M2-EDN各9人；M3-EDN、M3-QIN各8人。常规专催10人，按日有效在组人头均分队列当天目标，转组或离职前的既有目标保留，新人从生效日起承担。无人日列待分配。 |
| 个人达成 | 按工号先合计实收与序时目标，再算率并计人数。目标为0时单列。低于70%标红，恰好70%归中档，100%起为达标。超额提点门槛另行配置。 |
| 冻结＋Other | 原13万共用目标。11月17日起追加冻结人工3万，12个作业日，各2,500元，追踪与管理档父组合计16万，倒推档父组仍13万。原13万按全月25个作业日拆。经营总额只汇总父组一次；常规人催只含常规内催和委外。 |
| 工作日和预测 | 11月确认红日子为1、8、15、22、29日。日实收含红日回款，各组日目标按对应日历。预测分别用原队列全月和新队列上线后工作日进度外推。 |

月目标完成＝累计实收／月目标；序时达成＝累计实收／已过有效日目标之和；缺口＝序时目标－累计实收。管理表中“序时差额”通常展示相反方向，正数表示超序时，交付时在表头写清。每个父组每日及全月的子目标都应对平。
