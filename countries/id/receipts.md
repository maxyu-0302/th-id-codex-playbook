# 印尼实收如何对上财务

**经营实收**按回款日和流水关联的作业归属；**首分同池实收**按首次进入的案件池追踪，转组后仍跟原池。解释队列表时先选口径。M2-SCQ 是跨账龄队列，经营分拆使用回款时点账龄。诊断中未关联分案本金的回款单列。经营实收率分母可选累计分案逾期本金或全催剩本，报表合计先加分子分母再除。

| 环节 | 具体做法 |
|---|---|
| 正常回款 | 催收回款流水按 id 取最新版本，保留负向调整，以 repay_date 切当天业务窗口。通过 mission_log_id 对分案归属，控制关联基数。流水表金额按分折 IDR；财务标签金额按来源单位处理。 |
| 官方捞回 | 取数据组当月策略捞回标签。按资产、回款日期、期次，与常规、冻结及期次流水对重叠。已在经营范围的同笔回款转归 Other 只计一次。命中不能解释的重叠时，当前程序停止并要求迁移核验。自行寻找“未分案且有回款”的名单仅作诊断。 |
| 跨批次流水 | 先核两条记录同流水、不同批次、同一分案及催员，版本和期次金额也相符。以核实的排除 ID 重算经营、同池、PK、催员和趋势。对所有同金额或同资产记录直接去重会误删真实流水。 |
| 财务范围 | 常规＋M2-FRZ-REL＋M2-FRZ-REL-COL＋官方 Other。FRZ-NO-COLLECT 单列在该期财务范围外。新队列须核归属。 |
| 门禁 | 正常扣减额需与重复流水清单一致，官方标签需能还原到期次。财务差额留有方向，不能把确认的一次残差扩成全局容差。 |

**11月17日桥接样例，人民币。** 旧 HTML 753,066.95。按官方标签与重叠处理后扣 11,909.12，再扣跨批次重复 6,184.94，得到 734,972.88。财务 734,989.70，尾差 −16.82。标签毛额 74,882.14，当期净增量 74,877.98。各项基于未舍入金额计算。

**11月18日复核。** 正常范围 704,866.93 元，官方 Other 90,072.22 元，合计 794,939.15 元。财务 794,955.97 元，仍差 −16.82 元。扣重 336 条、6,184.94 元。用户接受本次尾差。这个结果对应 11 月 18 日的快照。复现时分别核当日数据，不沿用这个金​​额作调整分录。
