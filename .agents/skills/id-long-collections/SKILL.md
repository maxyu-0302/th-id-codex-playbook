# 印尼长账交接

在本仓库使用本技能时，从[国家入口](../../../countries/id/README.md)按业务问题选材料。若将技能安装到个人技能目录，保留仓库副本，用仓库根目录下 countries/id 读取知识和脚本。

- **生成日报或解释达成**：取指定业务日快照，用 tools/replay.py 复算。金额是人民币，分母为当组截至该日的追踪目标。冻结人工只在冻结段展开。补充催员分布时读取实际每日目标，以工号去重；明细不进入交接仓库。
- **判断回款去哪了**：按 receipts.md 对比官方标签、正常回款、去重及财务端。保留每一步的同口径金额、日期和残差；先解释归属迁移，再判断是否真有收款增减。
- **估分案、定目标、选策略**：从预测基点的有效池和成熟历史样本出发，用相同案件池比较原/现/新策略。明确每个参考率、金额边界、到账龄节点及队列的规则生效期。看净收益的同时核作业人数和负载。
- **输出决策**：给出证据、结论和适用范围。没有对应过程证据时只报缺口。提出切流方案时给出保本条件和下一次验证的观察窗口。发生目标批准、口径纠正或预测回测时，更新国家日志并记录替代版本。
- **查版本冲突**：先看 decisions.md 的生效日，再看项目对应月的正式配置；knowledge 内历史复盘中的单价、比例和备注用于解释当时版本。政企账号、登录状态、群授权和运行环境由接手人按环境配置。
