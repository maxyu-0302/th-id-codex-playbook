# 从经营问题到可复核的决策

先写决策所需的比较。判断当月落后用实际累计实收与同日累计目标；判断方案应否切换则把两种策略放到同一预测案件池，并算成本。把执行结果、预测和拟议调整分列，可以避免一次调高目标让预测实收也随之上升。

| 场景 | 能直接下的判断 | 下一步所需证据 |
|---|---|---|
| 累计实收落后 | 按可加总的金额缺口排序，报缺口和达成 | 拆分案本金规模、客群结构、同格实收率；只有接通或转化数据与相同人群、时段对齐后才能归因 |
| 团队整体过线 | 指出落后队列及其目标和实收 | 核在组生效日、个人目标覆盖；有回款无目标的人员另列 |
| 策略切换 | 同池预计净增量＝实收差额－成本差额 | 核路由边界、参考期、观察成熟度、人力负载和费率。分别测效果持平与预期提升场景 |
| 财务差异 | 报金额、方向、归属和未解释残差 | 固定业务日期、币种、换汇方向；核流水唯一性、原组、新组、冲正及成本覆盖 |
| 变更发布 | 根据已确认的规则生成输出 | 同一批次核日期、版本、金额及加总，保留校验结果和实际发布回执 |

## 记录一项判断

在对应国家的决策日志追加一条。写清 **日期与生效窗口、问题、证据和粒度、决定、待复核项、替代了哪条旧规则、复核日及结果**。同时记录“若出现什么事实就要改结论”。若月末有实际结果，回填预计值、实际值、误差及主要解释。只有重复验证的部分才提炼到技能；费率、名单、假期、客户边界和发送对象始终跟随当地当期配置。

例如，某队列月中开始作业。新增月目标应从生效日起分配，再加到父组。复核三个点：上线前日目标合计为零，所有作业日合计等于新增目标，父组、总表各只计一次。该例可以跨国复用，实际生效日和金额由国家档案给出。
