# 全球催收财务成本明细口径

来源：用户《实时成本口径 2026-10-15 21_54_11.xlsx》，工作表“实时成本口径”，28行、5列，2026-10-15读取；同日用户确认全球采用这一财务逻辑。该确认统一计算框架，不代表已验证所有国家的数仓实现或结算单，也不统一各国供应商单价、汇率、预算、税率、作业日历。后续明确修订优先。

## 财务成本树：只加同层项目

总成本 = 一线坐席成本 + 通讯成本 + 合规培训成本 + 税金成本 + 总部成本。

- 一线坐席成本 = 自营组员 + 自营组长 + 本地主管 + 国内主管 + 国家经理 + 本地职能 + 委外坐席 + 本地委外职能 + 本地行政all。
- 通讯成本 = 线路 + 预测式外呼 + 法催 + 小手机/SIM卡 + 短信 + WABA + IVR + AI + 猫池房租。
- 合规培训成本 = 本国质检人力 + 质检系统 + 本国培训人力。

不能将“一线坐席成本”理解为纯组员工资；不能同时加一级合计及其下属明细。对账分别检查三棵成本树与总成本，保留舍入差异，不强行补齐。

## 人力与预算分摊

定义 t = MTD自然日天数 / 当月自然日天数。人天是MTD上线人天，不是分案案件量，也不是截至日的在职人数。

| 项目 | 财务计算及分摊 |
|---|---|
| 自营组员：排名组 | 日人均成本 =（预算薪资＋法定节日加班费＋离职补偿＋年终奖＋年假结算）/预算人数/排班天数；队列成本=日人均成本×MTD上线人天 |
| 自营组员：提成组 | 上述日人均成本另加（实际日人均实收−预算日人均实收）×提成比例，再乘上线人天；原文没有规定负差额是否截零，不自行加MAX(0) |
| 自营组长 | 队列当月预算组长成本×t |
| 本地主管 | 当月地区预算×t×队列自营人天/本地区自营总人天 |
| 国内主管、国家经理 | 当月相应国家预算×t×队列自营人天/本国自营总人天 |
| 本地职能 | 具体逻辑写按本国自营人天分摊；概述写本地区，存在差异，见下方待确认 |
| 委外坐席：排名组 | 日人均成本=预算委外电催专员成本/预算人数/排班天数；乘队列MTD上线人天 |
| 委外坐席：提成组 | 上述日人均成本另加（实际日人均实收−预算日人均实收）×提成比例，再乘上线人天 |
| 本地委外职能 | 当月预算×t×队列委外人天/本国委外总人天 |
| 行政：房租物业水电 | 月预算×上月电催业务分摊比例×t×本队列自营职场人天/本地区自营职场总人天 |
| 行政：其他行政 | 月预算×上月电催业务分摊比例×t×本队列自营人天/本地区自营总人天 |

上述各队列结果再汇总到账龄。来源主要为人事行政部，委外坐席来源委外部，行政含IT部。

## 通讯、合规、税金与总部

| 项目 | 财务口径 |
|---|---|
| 线路、预测式外呼、短信、WABA、IVR、AI | Σ各供应商MTD消耗数量×各供应商当月结算单价；来源运营部 |
| 法催 | 坐席=预算开通数量×供应商当月单价×t；短信=实际MTD消耗×单价；两部分相加 |
| 小手机/SIM卡、猫池房租 | 相应月预算×t，按各队列线路消耗量占比分摊 |
| 本国质检人力、质检系统 | 月预算×t×队列MTD人天/本国MTD总人天（不只自营）；来源人事行政/运营 |
| 本国培训人力 | 月预算×t×自营队列MTD人天/本国自营MTD总人天 |
| 税金 | 本国当月税金预算×t，按各账龄实收占比分摊；来源财务 |
| 总部 | 总部电催职能及行政预算先计提MTD，按本国到期GMV本金/全球到期GMV本金分国，再按账龄实收比例分摊；来源人事行政及总部各部门 |

财务当月供应商单价不同于策略历史统一单价；“实际消耗×参考单价”应标策略预估，不能称财务已结算费用。

## 原文疑点：保留证据，不能静默修成已确认规则

- 总部公式原文“（…预算…）当月自然日总数*MTD自然日天数”遗漏运算符。结合“MTD预算成本”可理解为除以自然日总数，但这是解释；从预算重算前须确认，已有财务金额直接保留。
- 国内主管具体公式写“各国本地主管人力成本”，与项目名不一致，预算取项待核实。
- 本地职能概述按“本地区”，具体公式按“本国”，地域分摊范围待核实。
- 通讯汇总写“预测试外呼”，明细写“预测式外呼”；保留原名映射，不另算两份成本。
- 财务导出表常用“IM”，本文件写“WABA”；不能无依据认定二者完全相同。导出IM项按用户要求保留，其与WABA/其他IM渠道的映射另核实。
- 财务文件的委外“预算日均成本×上线人天＋提成差异”与策略“实收×费率”不是同一算法，不可互相覆盖。策略委外费率必须从对应国家、月份、合同或用户确认中获取，不能替换财务原值。
