# 通用方法

[知识库首页](../README.md) · [泰国](../02-泰国/README.md) · [印尼](../03-印尼/README.md)

| 业务问题 | 用法与产出 |
|---|---|
| 怎么读累计实收和目标？ | 月初至截止日的累计实收简称 MTD。累计实收 ÷ 同期累计目标得到序时达成；累计实收 ÷ 全月目标得到月目标完成。比较两个月时把截止日对齐。[指标与同期比较](../common/analysis.md) |
| 实收下降来自哪里？ | 同一范围下并排看分案金额、在手实收、实收率，再拆新老案、作业模式和大额回款。单看实收率无法判断总回款的变化。[分析步骤](../common/analysis.md) |
| 如何向财务解释净实收？ | 列出实收、成本、净实收。单独展示财务原数、策略调整和剩余差额，每项写明实际、估算或预算。[财务成本项目](../common/finance-methodology.md) · [泰国工作簿](../02-泰国/净实收.md) · [印尼工作簿](../03-印尼/净实收.md) |
| 能否根据历史结果决定扩量？ | 同一批案件上比较两种作业方式，先算实收差，再扣成本差。历史对照要记录可比范围；随机试验先测样本能否识别预期提升。[决策复盘](../common/decision-review.md) · [小概率回款试验计算脚本](../common/tools/rare_event_power.py) |
| 怎样用 Codex 更新已有分析？ | 给出国家、截止日、要做的决定和目标版本。从国家口径找数据，复算一组样例，最后回填证据、生效日和待核项。[分析技能](../.agents/skills/long-age-review/SKILL.md) · [维护方法](../common/maintenance.md) |

例如，同样是解释人工达成，泰国 11 月常规人工按固定考核人数和在队期间折算，印尼常规专催按每天实际在队人数分摊。两国都能用实收除以序时目标，个人目标的分母要回到各国配置。[泰国人员口径](../countries/th/metrics.md) · [印尼人员口径](../countries/id/targets.md)
